# Keyboard shortcuts

Shortcuts work with any keyboard layout, including Thai.

## Everywhere

| Keys | Action |
|---|---|
| Ctrl+P | Go to file |
| Ctrl+Shift+P | Command palette |
| Ctrl+B | Toggle sidebar |
| Ctrl+Alt+B | Toggle agent panel |
| Ctrl+` | Toggle terminal |
| Ctrl+Shift+` | New terminal |
| Ctrl+L | Focus agent input |
| Ctrl+Shift+E | Show Explorer |
| Ctrl+Shift+G | Show Source Control |
| Ctrl+, | Settings |
| F1 | User Manual |

## Editor and tabs

| Keys | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+W | Close tab |
| Ctrl+Tab | Next tab |

## Explorer and Source Control

| Keys | Action |
|---|---|
| F2 | Rename the selected file |
| Delete | Delete the selected file (to the Recycle Bin) |
| Ctrl+Enter | Commit (in the message box) |

## Agent chat

| Keys | Action |
|---|---|
| Enter | Send the message |
| Shift+Enter | New line |
