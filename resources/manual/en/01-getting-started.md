# Getting started

Taskmaster is a desktop IDE for building one project together with your team. Everyone works in their own copy of the project with their own coding agent (Claude Code first). Tasks, roles, notes and who is online are shared through git, so there is no server to run.

## The window

- **Activity bar** (far left): Explorer, Source Control, Tasks and Team. Click the active icon again to hide the sidebar. The gear opens Settings; your GitHub picture opens it too.
- **Sidebar**: the view you picked.
- **Editor** (center): files open as tabs. One click opens a preview tab (italic text); editing or double-clicking keeps it. A dot on a tab means unsaved changes.
- **Agent panel** (right): chat with your coding agent.
- **Terminal** (bottom): press Ctrl+` to open it.
- **Status bar** (bottom): current branch, git sync, team sync, GitHub account, language and theme. Click any item to use it.

## First steps

1. On first start the **Welcome** screen checks Git, your Git identity, GitHub and your coding agents. Fix the red rows and press **Continue**. You can run this check again from **Help → Setup Check**.
2. Create or open a project from the **Home** screen (**New project**, **Open folder**, **Clone repository**).
3. Open the **Team** view and enable Taskmaster for the project, then add your teammates, give them roles and create tasks.
4. Pick a task, press **Start task**, and talk to your agent in the right panel.

## Finding things

Press Ctrl+P to jump to a file and Ctrl+Shift+P for every command. Press F1 for this manual. The full key list is in the Keyboard shortcuts chapter.
