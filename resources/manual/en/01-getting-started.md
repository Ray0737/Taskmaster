# Getting started

Taskmaster is a desktop IDE for building one project together with your team. Each person drives their own coding agent, and the team shares tasks, roles and notes through git.

## The window

- **Activity bar** (far left): Explorer and other views. Click the active icon again to hide the sidebar.
- **Editor** (center): open files as tabs. A single click opens a preview tab (italic); editing or double-clicking keeps it.
- **Agent panel** (right): chat with your coding agent.
- **Terminal** (bottom): press Ctrl+` to open it.
- **Status bar** (bottom): language and theme; click to change them.

## Useful keys

| Keys | Action |
|---|---|
| Ctrl+P | Go to file |
| Ctrl+Shift+P | Command palette |
| Ctrl+B | Toggle sidebar |
| Ctrl+` | Toggle terminal |
| F1 | This manual |
