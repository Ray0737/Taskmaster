# งาน

งานคือหน้าที่หนึ่งชิ้นสำหรับหนึ่งคน มีรายละเอียด บทบาท และขอบเขตไฟล์ (ไม่บังคับ)

## การสร้างและแก้ไข

กด **+** ในมุมมองงาน พิมพ์ชื่องาน แล้วงานจะเปิดเป็นแท็บ ที่นั่นคุณตั้งค่า:

- **รายละเอียด**: ข้อความ Markdown สำหรับคนทำและ agent ของเขา (**ดูตัวอย่าง** แสดงผลลัพธ์)
- **บทบาท** และ **ผู้รับผิดชอบ**
- **สถานะ**: ต้องทำ, กำลังทำ, รอตรวจ, เสร็จแล้ว
- **ขอบเขต (glob ของไฟล์)**: เช่น `src/ui/**` พิมพ์ glob แล้วกด Enter agent จะถูกเตือน (ไม่ถูกบล็อก) เมื่อแก้ไฟล์นอกขอบเขต ถ้าว่างคือแก้ที่ไหนก็ได้
- **ลบงาน**: ลบงานและโน้ตของงานออกจากทั้งทีมหลังจากคุณยืนยัน ส่วน branch และ commit จะไม่ถูกแตะต้อง

การเปลี่ยนแปลงบันทึกเองหลังหยุดพิมพ์สักครู่

## มุมมองงาน

**ของฉัน** / **ทั้งหมด** สลับว่าจะเห็นงานของใคร และตัวกรองบทบาทช่วยจำกัดรายการ งานแบ่งกลุ่มเป็น กำลังทำ, ต้องทำ, รอตรวจ และ เสร็จแล้ว (กลุ่มเสร็จแล้วเริ่มต้นแบบพับไว้) ตัวเลขบนไอคอนงานนับงานที่ยังไม่เสร็จของคุณ

## การเริ่มงาน

กด **เริ่มงาน** (ในแท็บงาน หรือ **เริ่มงาน…** ในชุดคำสั่ง) Taskmaster จะ:

1. สร้าง branch `tm/<login ของคุณ>/<รหัสงาน>` จาก branch หลักของโปรเจกต์ (หรือสลับไปถ้ามีอยู่แล้ว) ถ้ามีการเปลี่ยนแปลงที่ยังไม่ commit จะถามให้ **เก็บไว้ชั่วคราว (stash)** หรือ **Commit เลย** ก่อน หรือยกเลิกก็ได้ ไม่ว่าเลือกแบบไหนก็ไม่มีอะไรหาย
2. ตั้งงานเป็น **กำลังทำ** และมอบหมายให้คุณถ้ายังไม่มีผู้รับผิดชอบ
3. ผูกแผง agent กับงานนี้ และแสดงว่าคุณกำลังทำงานนั้น

## การจบงาน

เมื่อ agent จบคำตอบด้วยสรุปสั้น ๆ ใน `<tm-note>` Taskmaster จะบันทึกเป็นโน้ตของงานและย้ายงานเป็น **รอตรวจ** ถ้า agent ไม่ได้เขียนไว้ จะมีกล่องเหนือช่องพิมพ์ให้บันทึกคำตอบล่าสุดเป็นโน้ต คุณเพิ่มโน้ตเองในแท็บงานได้ และกด **ส่งตรวจ** หรือ **ทำเครื่องหมายว่าเสร็จ** เอง

**เปิด pull request** (ในแท็บงานและใน Source Control บน branch `tm/…`) เปิดหน้า pull request ของ GitHub สำหรับ branch นั้น กดซิงก์ก่อนเพื่อให้ branch อยู่บน GitHub

โน้ตของทั้งทีมมองเห็นได้โดย agent ทุกตัว: โน้ตใหม่สุดห้ารายการถูกรวมในสิ่งที่ agent แต่ละตัวได้รับรู้ โน้ตเรื่อง endpoint ใหม่จากฝั่งแบ็กเอนด์จึงถึง agent ฝั่งฟรอนต์เอนด์

## ภาพหน้าจอ

เปิดงานแล้วกด **Ctrl+V** หลังคัดลอกรูป (เช่น ภาพแคปหน้าจอ) รูปจะขึ้นใต้ **ภาพหน้าจอ** คลิกเพื่อดูภาพใหญ่ หรือกดกากบาทเพื่อลบ ทีมเห็นรูปเหมือนโน้ต (สูงสุด 10 รูปต่องาน รูปละไม่เกิน 4 MB ชนิด png, jpg, webp หรือ gif) เมื่อ agent ทำงานโดยเลือกงานนี้ไว้ จะได้รับแจ้งที่อยู่ของรูปและเปิดดูได้ จึงส่งรูปแล้วสั่งว่า "ตรงนี้ผิด แก้ให้หน่อย" ได้

## เลือกหลายงาน

ในรายการงาน `Ctrl+คลิก` (หรือ `Space`) เพื่อเพิ่มหรือเอางานออกจากที่เลือก และ `Shift+คลิก` เพื่อเลือกทุกงานระหว่างคลิกครั้งก่อนกับครั้งนี้ จะมีแถบ **ตั้งสถานะ** **มอบให้ฉัน** และ **ลบ** สำหรับทุกงานที่เลือก คลิกธรรมดาจะเปิดงานเดียวและล้างการเลือก

## การแจ้งเตือน

กระดิ่งที่แถบซ้ายเปิด **การแจ้งเตือน** แสดงสิ่งที่เพื่อนร่วมทีมทำที่เกี่ยวกับคุณ (งานที่มอบให้คุณ โน้ตในงานที่คุณเป็นเจ้าของหรือสร้าง มีคนเริ่มทำงาน) และข้อเสนองานจาก agent ของคุณเอง ตัวเลขบนไอคอนคือจำนวนที่ยังไม่ได้อ่าน

เมื่อมีหลายคนในทีม agent ของคุณรู้ว่าใครอยู่ในทีมบ้าง ถ้างานส่วนหนึ่งเป็นของเพื่อนร่วมทีม agent อาจจบคำตอบด้วยข้อเสนอ แต่จะยังไม่สร้างอะไรทั้งนั้น ข้อเสนอจะขึ้นในการแจ้งเตือน และต้องกด **อนุมัติและมอบงาน** จึงจะสร้างงานให้เพื่อนคนนั้น **ปิด** คือทิ้งข้อเสนอ ข้อเสนอสำหรับคนที่ไม่ได้อยู่ในทีมจะถูกปฏิเสธ ข้อเสนอเก็บไว้เฉพาะตอนที่แอปเปิดอยู่
