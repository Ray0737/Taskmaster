# การลงชื่อเข้าใช้

Taskmaster ไม่มีบัญชีของตัวเอง แต่ใช้สิ่งที่มีอยู่แล้วในเครื่องคุณ คือ Git และการล็อกอิน GitHub ที่ Git Credential Manager (ติดตั้งมากับ Git for Windows) หรือ GitHub CLI (`gh`) เก็บไว้

## สิ่งที่ต้องมี

- **Git** (จำเป็น) ถ้าไม่มี หน้าต้อนรับจะมีลิงก์ไปหน้าดาวน์โหลด
- **ตัวตนใน Git** (จำเป็น): ชื่อและอีเมลของคุณ ถ้ายังไม่ได้ตั้ง ให้พิมพ์ในหน้าต้อนรับแล้วกด **บันทึก** ระบบเก็บด้วย `git config --global`
- **GitHub** (ไม่บังคับ): ใช้สำหรับเลือก repository สร้าง repository เชิญเพื่อนร่วมทีม และแสดงรูปของคุณ

## การเชื่อมต่อ GitHub

ถ้าคุณล็อกอินด้วย `gh` หรือ Git Credential Manager อยู่แล้ว Taskmaster จะพบเองและแสดง "เข้าสู่ระบบเป็น @คุณ" ถ้ายังไม่ได้ล็อกอิน กด **เชื่อมต่อ GitHub** หน้าต่างล็อกอินของ Git Credential Manager จะเปิดในเบราว์เซอร์ เมื่อคุณอนุมัติแล้ว แถวจะเปลี่ยนเป็นสีเขียว

token อยู่ในหน่วยความจำเท่านั้น ไม่ถูกเขียนลงดิสก์และไม่แสดงให้เห็น **การตั้งค่า → บัญชี** แสดงว่าคุณคือใครและมีปุ่ม **เชื่อมต่อใหม่**

## โหมด git อย่างเดียว

ถ้าไม่มีการล็อกอิน GitHub งานทุกอย่างของ git ยังใช้ได้ ทั้งเปิดโฟลเดอร์ clone ด้วย URL commit branch และซิงก์ แต่ฟีเจอร์เหล่านี้จะปิด และแอปจะบอกเหตุผลเมื่อคุณไปถึง:

- เลือก repository จากรายการ GitHub ของคุณตอน clone
- สร้าง GitHub repository ให้โปรเจกต์ใหม่
- เชิญเพื่อนร่วมทีมจากมุมมองทีม (คุณเพิ่มเขาด้วย login แล้วขอให้เขารับสิทธิ์บน GitHub เอง)

แถบสถานะแสดง **GitHub: โหมดออฟไลน์** คลิกเพื่อเชื่อมต่อภายหลัง
