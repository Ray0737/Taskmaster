# ธีมและภาษา

## ธีม

มีธีมให้สี่แบบ:

- **Mono Dark** (ค่าเริ่มต้น): พื้นดำ ตัวอักษรเทา ไม่มีสีอื่นนอกจากสีแดงสำหรับข้อผิดพลาด
- **Mono Light**: แบบเดียวกันบนพื้นขาว
- **Catppuccin Mocha**: สีเน้นม่วงบนพื้นน้ำเงินเทาเข้ม
- **GitHub Dark**: โทนสีมืดของ GitHub

เปลี่ยนธีมได้ที่ **การตั้งค่า → ทั่วไป** (คลิกตัวอย่างสี) หรือคลิกชื่อธีมในแถบสถานะ หรือใช้คำสั่ง **เปลี่ยนธีม…** (Ctrl+Shift+P) ตัวแก้ไข เทอร์มินัล และปุ่มของหน้าต่างเปลี่ยนตามไปด้วย

## ภาษา

ภาษาหลักคืออังกฤษ และมีภาษาไทย สลับได้ที่ **การตั้งค่า → ทั่วไป** หรือรายการ **EN / TH** ในแถบสถานะ หรือในหน้าต้อนรับ ทั้งแอปเปลี่ยนพร้อมกัน ไม่ต้องเปิดใหม่ คู่มือนี้ตามภาษาของแอป และมีปุ่ม **EN / TH** ของตัวเอง

เมนูภายในตัวแก้ไขโค้ด (เช่น กล่องค้นหา) ยังเป็นภาษาอังกฤษ

## การตั้งค่าตัวแก้ไข

**การตั้งค่า → ตัวแก้ไข** มีขนาดฟอนต์ (10–24) การบันทึกอัตโนมัติ (ปิด หรือหนึ่งวินาทีหลังหยุดพิมพ์) และการตัดบรรทัดอัตโนมัติ
