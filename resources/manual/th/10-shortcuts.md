# ปุ่มลัด

ปุ่มลัดใช้ได้กับทุกแป้นพิมพ์ รวมถึงแป้นไทย

## ใช้ได้ทุกที่

| ปุ่ม | การทำงาน |
|---|---|
| Ctrl+P | ไปที่ไฟล์ |
| Ctrl+Shift+P | ชุดคำสั่ง |
| Ctrl+B | เปิด/ปิดแถบข้าง |
| Ctrl+Alt+B | เปิด/ปิดแผง Agent |
| Ctrl+` | เปิด/ปิดเทอร์มินัล |
| Ctrl+Shift+` | เทอร์มินัลใหม่ |
| Ctrl+L | โฟกัสช่องพิมพ์ Agent |
| Ctrl+Shift+E | แสดงตัวสำรวจ |
| Ctrl+Shift+G | แสดงการควบคุมต้นฉบับ |
| Ctrl+, | การตั้งค่า |
| F1 | คู่มือการใช้งาน |

## ตัวแก้ไขและแท็บ

| ปุ่ม | การทำงาน |
|---|---|
| Ctrl+S | บันทึก |
| Ctrl+W | ปิดแท็บ |
| Ctrl+Tab | แท็บถัดไป |

## ตัวสำรวจและ Source Control

| ปุ่ม | การทำงาน |
|---|---|
| F2 | เปลี่ยนชื่อไฟล์ที่เลือก |
| Delete | ลบไฟล์ที่เลือก (ไปถังรีไซเคิล) |
| Ctrl+Enter | Commit (ในกล่องข้อความ) |

## แชท Agent

| ปุ่ม | การทำงาน |
|---|---|
| Enter | ส่งข้อความ |
| Shift+Enter | ขึ้นบรรทัดใหม่ |
