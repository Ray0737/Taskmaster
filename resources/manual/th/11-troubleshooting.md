# การแก้ปัญหา

หาอาการที่พบ แล้วดูวิธีแก้

## การตั้งค่า

| อาการ | วิธีแก้ |
|---|---|
| หน้าต้อนรับบอกว่าไม่พบ Git | ติดตั้ง Git for Windows แล้วกด **ตรวจสอบอีกครั้ง** |
| ไปต่อจากหน้าต้อนรับไม่ได้ | ต้องมี Git และตัวตนใน Git (ชื่อและอีเมล) ส่วน GitHub และ agent ไม่บังคับ |
| แถบสถานะบอก "GitHub: โหมดออฟไลน์" | คลิกแล้วลงชื่อเข้าใช้ หรือเปิด **การตั้งค่า → บัญชี → เชื่อมต่อใหม่** ถ้าไม่มี GitHub ก็ยังใช้ git ได้ |
| Clone หรือ push บอกว่ายืนยันตัวตนไม่ผ่าน | กด **เชื่อมต่อ GitHub** (การตั้งค่า → บัญชี → เชื่อมต่อใหม่) แล้วลองอีกครั้ง |

## โปรเจกต์และ git

| อาการ | วิธีแก้ |
|---|---|
| "ไม่ใช่ git repository" ตอนเปิดโฟลเดอร์ | เลือก **เริ่มใช้ git** หรือเปิดโฟลเดอร์หลักของ repository แทนโฟลเดอร์ย่อย |
| ซิงก์บอกว่า remote มี commit ใหม่ | กด **ซิงก์** อีกครั้ง ระบบ pull ก่อนเสมอ |
| "มี conflict — แก้ไขในเทอร์มินัล" | กด **เปิดเทอร์มินัล** รัน `git status` แก้ไฟล์ที่ระบุ `git add` แล้ว `git rebase --continue` |
| สลับ branch ไม่ได้ | git ปกป้องการแก้ไขที่ยังไม่ commit ของคุณ ให้ commit หรือ stash ก่อนแล้วสลับ |
| ไฟล์บนดิสก์เปลี่ยนขณะเปิดอยู่ | จะมีแถบให้เลือก **โหลดใหม่**, **ใช้ของฉัน** หรือ **เปรียบเทียบ** |
| ไฟล์ที่เปิดอยู่ถูกลบ | ชื่อแท็บถูกขีดฆ่าและแก้ไม่ได้ ให้ปิดแท็บ |
| เทอร์มินัลไม่เปิด | ส่วนเทอร์มินัลเริ่มไม่ได้ เปิด **ช่วยเหลือ → เปิดโฟลเดอร์ log** แล้วดู `main.log` การติดตั้งแอปใหม่มักแก้ได้ |

## ทีม

| อาการ | วิธีแก้ |
|---|---|
| **เปิดใช้ Taskmaster** บอกว่าไม่มี remote | สร้าง GitHub repository (Source Control → ซิงก์ หลังเพิ่ม remote หรือโปรเจกต์ใหม่แบบติ๊ก "สร้าง GitHub repository") แล้วเปิดใช้ |
| บอกให้ commit แรกก่อน | commit อะไรสักอย่างแล้วเปิดใช้ |
| มุมมองทีมว่างหรือเก่า | รายการในแถบสถานะบอกเหตุผล: ออฟไลน์ หยุดชั่วคราว หรือขัดแย้ง คลิกเพื่อซิงก์เดี๋ยวนี้ |
| "ซิงก์ขัดแย้ง" สีแดง | คลิกรายการแล้วเลือก **รีเซ็ตเป็นเวอร์ชันบนเซิร์ฟเวอร์** สิ่งที่หายมีแค่การเปลี่ยนแปลงทีมของคุณที่ยังไม่ซิงก์ |
| ไม่เห็นการเปลี่ยนแปลงของเพื่อนร่วมทีม | จะปรากฏหลังเขา push ครั้งถัดไปและคุณ fetch ครั้งถัดไป (ค่าเริ่มต้น 15 วินาที) คลิกรายการในแถบสถานะเพื่อ fetch เดี๋ยวนี้ |
| เชิญเพื่อนร่วมทีมไม่ได้ | ถ้าไม่มีสิทธิ์ GitHub Taskmaster เชิญไม่ได้ ให้เพิ่มเข้าทีมไว้ก่อนแล้วให้สิทธิ์เขียนบน GitHub |

## Agent

| อาการ | วิธีแก้ |
|---|---|
| "ยังไม่ได้เชื่อมต่อ agent" | ติดตั้ง Claude Code (หรือ CLI อื่นที่รองรับ) ให้อยู่ใน PATH แล้ว **สแกนใหม่** |
| "agent ยังไม่ได้ลงชื่อเข้าใช้" | กด **เปิดเทอร์มินัลเพื่อลงชื่อเข้าใช้** แล้วล็อกอินให้เสร็จ |
| "ถูกบล็อกเพราะโหมดปัจจุบัน" | เปลี่ยนโหมดเป็น **แก้ไขได้** หรือ **เต็มรูปแบบ** แล้วขอใหม่ |
| ข้อผิดพลาดพร้อม **ลองใหม่** | อ่านบรรทัดใต้ข้อความ แก้สาเหตุ (เครือข่าย การล็อกอิน เส้นทาง) แล้วกด **ลองใหม่** |
| agent เริ่มช้า | hook และ plugin ของ Claude ของคุณรันเหมือนในเทอร์มินัล อาจเพิ่มเวลาหลายวินาที |
| Codex, Gemini, Aider หรือ opencode ไม่มีแถวเครื่องมือ | รองรับพื้นฐานเท่านั้น: ตอบเป็นข้อความธรรมดาหนึ่งครั้งต่อหนึ่งข้อความ |

## ตัวแอป

| อาการ | วิธีแก้ |
|---|---|
| แผงแสดง "… เกิดข้อผิดพลาด" | กด **โหลดมุมมองใหม่** ส่วนอื่นของแอปยังทำงานต่อ |
| เกิดเหตุแปลก ๆ | **ช่วยเหลือ → เปิดโฟลเดอร์ log** แล้วดู `main.log` |

## ที่ยังไม่มีในเวอร์ชันนี้

การแก้ไขไฟล์เดียวกันพร้อมกันแบบเรียลไทม์ ตัวแก้ merge conflict การรีวิว pull request ในแอป และระบบปฏิบัติการอื่นนอกจาก Windows
