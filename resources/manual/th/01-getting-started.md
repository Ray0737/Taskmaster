# เริ่มต้นใช้งาน

Taskmaster คือ IDE บนเดสก์ท็อปสำหรับทำโปรเจกต์เดียวกันร่วมกับทีม แต่ละคนทำงานในสำเนาโปรเจกต์ของตัวเองพร้อม coding agent ของตัวเอง (เริ่มจาก Claude Code) งาน บทบาท โน้ต และสถานะว่าใครออนไลน์ แชร์กันผ่าน git จึงไม่ต้องรันเซิร์ฟเวอร์

## หน้าต่างโปรแกรม

- **แถบกิจกรรม** (ซ้ายสุด): ตัวสำรวจ, การควบคุมต้นฉบับ (Source Control), งาน และทีม คลิกไอคอนที่เปิดอยู่ซ้ำเพื่อซ่อนแถบข้าง ไอคอนเฟืองเปิดการตั้งค่า รูปโปรไฟล์ GitHub ของคุณก็เปิดการตั้งค่าเช่นกัน
- **แถบข้าง**: มุมมองที่คุณเลือก
- **ตัวแก้ไข** (ตรงกลาง): ไฟล์เปิดเป็นแท็บ คลิกครั้งเดียวจะเปิดแท็บพรีวิว (ตัวเอียง) เมื่อแก้ไขหรือดับเบิลคลิกแท็บจะค้างไว้ จุดบนแท็บหมายถึงมีการแก้ไขที่ยังไม่บันทึก
- **แผง Agent** (ขวา): คุยกับ coding agent ของคุณ
- **เทอร์มินัล** (ล่าง): กด Ctrl+` เพื่อเปิด
- **แถบสถานะ** (ล่างสุด): branch ปัจจุบัน การซิงก์ git การซิงก์ทีม บัญชี GitHub ภาษา และธีม คลิกรายการใดก็ได้เพื่อใช้งาน

## ขั้นตอนแรก

1. เมื่อเปิดครั้งแรกหน้า **ยินดีต้อนรับ** จะตรวจสอบ Git ตัวตนใน Git GitHub และ coding agent ของคุณ แก้แถวที่เป็นสีแดงแล้วกด **ดำเนินการต่อ** ตรวจสอบซ้ำได้จาก **ช่วยเหลือ → ตรวจสอบการตั้งค่า**
2. สร้างหรือเปิดโปรเจกต์จากหน้า **เริ่มต้น** (**โปรเจกต์ใหม่**, **เปิดโฟลเดอร์**, **Clone repository**)
3. เปิดมุมมอง **ทีม** แล้วเปิดใช้ Taskmaster สำหรับโปรเจกต์ จากนั้นเพิ่มเพื่อนร่วมทีม กำหนดบทบาท และสร้างงาน
4. เลือกงาน กด **เริ่มงาน** แล้วคุยกับ agent ในแผงด้านขวา

## ค้นหาสิ่งที่ต้องการ

กด Ctrl+P เพื่อไปที่ไฟล์ และ Ctrl+Shift+P เพื่อดูทุกคำสั่ง กด F1 เพื่อเปิดคู่มือนี้ รายการปุ่มลัดทั้งหมดอยู่ในบทปุ่มลัด
