# เริ่มต้นใช้งาน

Taskmaster คือ IDE บนเดสก์ท็อปสำหรับทำโปรเจกต์เดียวกันร่วมกับทีม แต่ละคนใช้ coding agent ของตัวเอง และทีมแชร์งาน บทบาท และโน้ตผ่าน git

## หน้าต่างโปรแกรม

- **แถบกิจกรรม** (ซ้ายสุด): ตัวสำรวจและมุมมองอื่น ๆ คลิกไอคอนที่เปิดอยู่ซ้ำเพื่อซ่อนแถบข้าง
- **ตัวแก้ไข** (ตรงกลาง): เปิดไฟล์เป็นแท็บ คลิกครั้งเดียวจะเปิดแท็บพรีวิว (ตัวเอียง) เมื่อแก้ไขหรือดับเบิลคลิกแท็บจะค้างไว้
- **แผง Agent** (ขวา): คุยกับ coding agent ของคุณ
- **เทอร์มินัล** (ล่าง): กด Ctrl+` เพื่อเปิด
- **แถบสถานะ** (ล่างสุด): ภาษาและธีม คลิกเพื่อเปลี่ยน

## ปุ่มลัดที่ใช้บ่อย

| ปุ่ม | การทำงาน |
|---|---|
| Ctrl+P | ไปที่ไฟล์ |
| Ctrl+Shift+P | ชุดคำสั่ง |
| Ctrl+B | เปิด/ปิดแถบข้าง |
| Ctrl+` | เปิด/ปิดเทอร์มินัล |
| F1 | คู่มือนี้ |
