# Agent

แผงด้านขวาคุยกับ coding agent ที่รันบนเครื่องของคุณ ภายในโฟลเดอร์โปรเจกต์

## Agent ที่รองรับ

Taskmaster ค้นหาโปรแกรมเหล่านี้ใน PATH ตอนเริ่มและเมื่อคุณกด **สแกนใหม่** (การตั้งค่า → Agents):

- **Claude Code**: รองรับเต็มรูปแบบ: ข้อความสด แถวเครื่องมือ diff ค่าใช้จ่าย และการจำบทสนทนา
- **Codex CLI, Gemini CLI, Aider, opencode**: รองรับพื้นฐาน: ตอบหนึ่งครั้งต่อหนึ่งข้อความเป็นข้อความธรรมดา ไม่จำบทสนทนา ไม่มีแถวเครื่องมือ

ถ้าไม่พบเลย แผงจะอธิบายวิธีติดตั้ง Claude Code

## เซสชันที่ผ่านมา

ไอคอนนาฬิกาที่หัวแผงแชท (และหน้าแชทว่าง) แสดงบทสนทนา Claude Code ก่อนหน้าของโปรเจกต์นี้ใต้หัวข้อ **เซสชันที่ผ่านมา** เลือกอันใดก็ได้เพื่อดูและคุยต่อจากจุดเดิม

## ช่องพิมพ์

ตัวควบคุมอยู่ในแถบใต้ช่องพิมพ์ เหมือนส่วนเสริม Claude ของ VS Code ทางขวาคือข้อความสถานะและปุ่มส่ง ซึ่งจะเปลี่ยนเป็น **หยุด** ขณะ agent ทำงาน

- **Agent**: เลือกโปรแกรมที่จะใช้
- **โหมด** (Claude Code): **อ่านอย่างเดียว** (agent ดูได้แต่แก้อะไรไม่ได้), **แก้ไขได้** (แก้ไฟล์ได้ คำสั่ง shell ส่วนใหญ่ถูกบล็อกเพราะไม่มีใครอนุมัติในแอปได้), **เต็มรูปแบบ** (รันคำสั่งใดก็ได้ แสดงพร้อมคำเตือนสีแดง) ค่าเริ่มต้นคือ **แก้ไขได้** เปลี่ยนค่าเริ่มต้นได้ที่การตั้งค่า → Agents
- **งาน**: งานที่ agent กำลังทำ หรือ "ไม่ระบุงาน" สำหรับแชททั่วไปที่ยังรู้บทบาทของคุณและงานของเพื่อนร่วมทีม
- **บริบท** (ไอคอน info): แสดงสิ่งที่ agent ได้รับรู้เกี่ยวกับบทบาท งาน ขอบเขตไฟล์ เพื่อนร่วมทีม และโน้ตล่าสุดของคุณอย่างตรงไปตรงมา

## การแชท

พิมพ์ในกล่องด้านล่าง Enter ส่ง Shift+Enter ขึ้นบรรทัดใหม่ ขณะ agent ทำงาน ปุ่มจะเป็น **หยุด** ซึ่งจะยุติ agent และทุกอย่างที่มันเริ่มไว้

บทสนทนาแสดงข้อความของคุณ คำตอบของ agent (Markdown มีปุ่มคัดลอกที่บล็อกโค้ด) และหนึ่งบรรทัดต่อการเรียกเครื่องมือ (เช่น "Edit src/App.tsx") คลิกบรรทัดเพื่อดูอินพุตและเอาต์พุต คลิกชื่อไฟล์เพื่อเปิดไฟล์ หรือสำหรับการแก้ไข จะเปิด diff เทียบกับ commit ล่าสุด

ส่วนท้ายแสดงจำนวน token และสำหรับ Claude Code มีค่าใช้จ่ายของคำตอบล่าสุด

บทสนทนาต่อจากเดิมได้ แยกตามโปรเจกต์และตามงาน แม้ปิดแล้วเปิดแอปใหม่ **แชทใหม่** เริ่มจากศูนย์

## ข้อความจาก Taskmaster

- **ถูกบล็อกเพราะโหมดปัจจุบัน**: agent ต้องการทำสิ่งที่โหมดไม่อนุญาต (มักเป็นการรันคำสั่ง) เปลี่ยนเป็นโหมดแก้ไขได้หรือเต็มรูปแบบแล้วขอใหม่
- **อยู่นอกขอบเขตของงาน**: agent แก้ไฟล์ที่ไม่อยู่ในขอบเขตของงาน ตรวจดูการเปลี่ยนแปลง ไม่มีอะไรถูกบล็อก
- **agent ยังไม่ได้ลงชื่อเข้าใช้**: กด **เปิดเทอร์มินัลเพื่อลงชื่อเข้าใช้** แล้วทำการล็อกอินให้เสร็จที่นั่น
- **agent หยุดทำงานเพราะเกิดข้อผิดพลาด**: แสดงบรรทัดท้าย ๆ ของข้อผิดพลาดพร้อม **ลองใหม่**

## การตั้งค่า Claude ของคุณเอง

Claude Code รันด้วยการตั้งค่าปกติของคุณ รวมถึง hook และ plugin ของคุณเอง สิ่งเหล่านี้อาจเพิ่มข้อความในคำตอบหรือทำให้เริ่มช้า เหมือนที่เกิดในเทอร์มินัล
