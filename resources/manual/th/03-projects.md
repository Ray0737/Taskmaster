# โปรเจกต์

โปรเจกต์คือ git repository ธรรมดาในโฟลเดอร์ธรรมดา ไม่มีอะไรพิเศษถูกเพิ่มเข้าไป

## หน้าเริ่มต้น

เมื่อไม่ได้เปิดโฟลเดอร์ พื้นที่ตัวแก้ไขจะแสดง **เริ่มต้น** (โปรเจกต์ใหม่, เปิดโฟลเดอร์, Clone repository) และ **ล่าสุด** เอาเมาส์ชี้โปรเจกต์ล่าสุดเพื่อเอาออกจากรายการ (ตัวโฟลเดอร์จะไม่ถูกแตะต้อง)

## โปรเจกต์ใหม่

**โปรเจกต์ใหม่** ถามชื่อและตำแหน่ง (**เลือก…**) แล้วสร้างโฟลเดอร์ รัน `git init` เขียน README และ commit แรก ติ๊ก **สร้าง GitHub repository** (และ **Repository ส่วนตัว**) เพื่อสร้างบน GitHub และ push ทันที ต้องมีการล็อกอิน GitHub ถ้า GitHub ล้มเหลว โปรเจกต์ในเครื่องยังถูกสร้างและคุณจะเห็นคำเตือน

ชื่อห้ามมี `\ / : * ? " < > |` ห้ามลงท้ายด้วยจุดหรือช่องว่าง และห้ามเป็นชื่อที่ Windows สงวนไว้ เช่น `CON`

## เปิดโฟลเดอร์

เลือกโฟลเดอร์ใดก็ได้ ถ้าไม่ใช่โฟลเดอร์หลักของ git repository Taskmaster จะเสนอให้ **เริ่มใช้ git** ถ้าคุณมีการแก้ไขที่ยังไม่บันทึกในโปรเจกต์ปัจจุบัน ระบบจะถามก่อนทิ้ง

## Clone repository

- แท็บ **GitHub**: ค้นหา repository ของคุณ (รวมองค์กรที่คุณอยู่) แล้วเลือก
- แท็บ **URL**: วาง git URL ใดก็ได้ ชื่อโฟลเดอร์จะถูกเติมให้

เลือก **Clone ไปที่** แล้วกด **Clone** แถบความคืบหน้าแสดงการดาวน์โหลด และ **ยกเลิก** จะหยุดการ clone โปรเจกต์จะเปิดเมื่อเสร็จ

## การปิดโปรเจกต์

**ไฟล์ → ปิดโฟลเดอร์** จะกลับไปหน้าเริ่มต้น Taskmaster หยุดซิงก์ทีมขณะไม่มีโปรเจกต์เปิดอยู่

## ตัวอย่าง Markdown

คลิกขวาที่ไฟล์ `.md` ในตัวสำรวจแล้วเลือก **เปิดตัวอย่าง** เพื่ออ่านแบบเรนเดอร์ มีหัวข้อ ตาราง และลิงก์ ตัวอย่างตามการแก้ไขของคุณ ทั้งที่บันทึกและยังไม่บันทึก แก้ในตัวอย่างไม่ได้ ให้แก้ในแท็บของไฟล์ ลิงก์เปิดในเบราว์เซอร์ คำสั่งเดียวกันอยู่ในพาเลตต์คำสั่งชื่อ "เปิดตัวอย่าง Markdown"

## ภาษาและการรันไฟล์

ตัวแก้ไขใส่สีให้ Python, C, C++, C#, Java, Go, JavaScript, TypeScript, JSX และ TSX, JSON, HTML, CSS, Markdown, shell และอีกมากตามนามสกุลไฟล์ สเก็ตช์ Arduino (`.ino`) แสดงเป็น C++ และไฟล์โปรเจกต์ .NET (`.csproj`, `.xaml`) แสดงเป็น XML JavaScript และ TypeScript แนะนำโค้ดภายในไฟล์และบอกข้อผิดพลาดด้านไวยากรณ์ แต่ไม่ขีดเส้นใต้ import เพราะตัวแก้ไขไม่อ่าน `node_modules`

กดปุ่มเล่นเหนือโค้ด หรือ **รันไฟล์** (Ctrl+F5) เพื่อรันไฟล์ปัจจุบันในเทอร์มินัลด้วยเครื่องมือที่มีในเครื่อง: `python`, `node`, `npx tsx` (TypeScript และ TSX), `gcc` และ `g++` (คอมไพล์ลงโฟลเดอร์ชั่วคราว), `dotnet run`, `java` และ `go run` ต้องติดตั้งเครื่องมือและอยู่ใน PATH ถ้ามีการแก้ที่ยังไม่บันทึกจะบันทึกก่อน สเก็ตช์ Arduino ยังรันไม่ได้
